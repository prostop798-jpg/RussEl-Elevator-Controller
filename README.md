## 🚀 Как установить и запустить

### Вариант 1: Быстрый старт (через демо-файл)
1.  Скачайте файл `RussEL Demo 2.0 Fixed.rbxl`.
2.  Откройте его в Roblox Studio.
3.  Нажмите **Play** и протестируйте лифт.

### Вариант 2: Интеграция в свой проект
1.  Скопируйте папку `RussEL Elevator 2.0` со всеми вложенными объектами в `Workspace` вашего проекта.
2.  Убедитесь, что скрипт `RussEL Elevator Engine` находится внутри этой папки.
3.  Настройте параметры в начале скрипта `RussELElevatorEngine.luau`:
    *   `TRAVEL_SPEED` — скорость движения кабины (studs/sec).
    *   `DOOR_OPEN_TIME` — время полного открытия дверей (секунды).
    *   `FLOOR_HEIGHT` — высота одного этажа (studs).
4.  Для вызова действий используйте методы из объекта `API`:
    ```lua
    local elevatorAPI = workspace.RussEL Elevator 2.0.API
    elevatorAPI:GoToFloor(3)
    elevatorAPI:OpenDoor()
    ```
